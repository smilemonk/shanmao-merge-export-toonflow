# 批量生成 · Toonflow 画布节点插件

作者：山猫

「批量生成」是一个 **Toonflow 画布节点插件**。安装后，在 Toonflow 画布中添加「批量生成」节点，就能挑选要生成的节点，按画布连线分批执行。

## 功能

| 勾选方式 | 用法 |
| --- | --- |
| 分类快选 | 一次勾选视频、图片、音频或文本中的一类。不同类别可以叠加。 |
| 逐个勾选 | 在清单里按节点勾选或取消，也可以在分类快选后逐个调整。 |
| 未生成 | 一次勾选当前没有生成结果的节点，方便补跑。 |

打开面板时默认零勾选。清单按类型和名称排序，长名称悬停可看全。也可框选画布节点，再用选区工具栏里的「批量生成」打开确认清单。

点击执行后，同层节点同时提交，全部成功后才进入下一层。某个节点失败时，已提交的同层任务继续处理，后续层停止提交。正在生成的节点会等待已有任务。点击停止会停止等待，并对本批发起且仍在处理的节点请求取消。

## 费用说明

面板通过 **Toonflow 自带的估价功能**取得所选媒体节点的报价，并汇总显示，例如「约 2.4 元」。只有部分节点返回报价时，面板会标出已估价的数量。文本生成可能由供应商单独计费。

**面板金额仅供参考，实际费用以供应商的最终结算为准。** 执行前请核对勾选清单、模型和参数。重新执行已有结果的节点可能覆盖结果并再次计费。

## 安装

1. 下载 [shanmaoBatchGenerate.umd.js](build/shanmaoBatchGenerate.umd.js)。
2. 在 Toonflow 设置的插件管理中安装该文件。
3. 打开画布，添加「批量生成」节点。默认宽 210 像素，右下角可拖拽调节。

如果安装过 1.0.3 或更早的版本，新版使用更正后的节点标识。先把画布里的节点换成新版，再卸载旧版。

## 开发

在 Toonflow 2.0.10 的 SDK 和画布组件上验证了安装包的界面与模拟任务流程。

本地安装 Toonflow 插件开发工具后，在项目根目录运行：

```sh
bun run build
bun test
```

构建脚本默认查找 macOS 上 Toonflow 已准备的 SDK。其他安装位置可设置 `TOONFLOW_PLUGIN_SDK`，指向包含 `pluginBuild.js` 和 `thirdPartyNotices/` 的官方 SDK 目录。发布文件为 `build/shanmaoBatchGenerate.umd.js`，插件标识为 `shanmaoBatchGenerate`。SDK 许可证声明随安装包提供。

Agent 可用 `inspectQueue` 读取计划。执行入口 `startQueue` 要求明确提供非空的 `nodeIds` 和 `confirm: true`。

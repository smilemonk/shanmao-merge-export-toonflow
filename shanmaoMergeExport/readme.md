# 合并导出视频 · Toonflow 画布节点插件

作者：山猫

把画布上视频节点当前显示的素材，按名称顺序合并导出成一个视频。仅做合并，不做任何修改。

## 它怎么工作

1. 列出画布上所有视频节点，按名称排序依次排列（段1 → 段2 → 段3 → ……），勾选要合并的视频
2. 合并前检查各段视频的编码参数（编码器 / 分辨率 / 音频参数）是否一致，一致则直接流拷贝拼接
3. 参数不一致时（例如混了 720p 和 1080p 的段）不会闷头执行：列出哪一段差在哪个参数后，会按参数分档让你选择以哪一档为准（例如「以 1080x1920 为准 —— 9 段原样，1 段转码」）。选定的档原样不动，其余段转码对齐到该档（画面保持原比例、不足处补黑边），然后拼接
4. 转码对齐产生的中间文件保存在 input/画布名字/transcoded/ 目录，可随时清理
5. 每段视频取该节点当前显示的这版素材（节点重新生成过，就用最新的）

## 输出目录

```
合并导出视频/
├── 画布名字_20261107_033012.mp4          ← 每次导出的成片，文件名带日期时间
├── 画布名字_20261107_041532.mp4
└── input/
    └── 画布名字/
        ├── 画布名字_20261107_032510.txt  ← 每次导出的素材清单
        └── 画布名字_20261107_033012.txt
```

- 成片文件名 = 画布名 + 日期时间，每次导出都是新文件，不会覆盖任何旧片
- 每次导出在 input 下留一份带日期时间的清单，记录本次合并了哪些素材、什么顺序
- 素材片段保留在原处，不额外复制，不占用额外空间

## 用法

1. 画布添加「合并导出视频」节点（每张画布放一个即可）
2. 面板自动列出视频节点，勾选要合并的（默认勾选已生成的）
3. 点「合并导出」，完成后节点里直接预览成片，也可连线下游或下载

## 安装

1. 下载 [shanmaoMergeExport.umd.js](build/shanmaoMergeExport.umd.js)。
2. 在 Toonflow 设置的插件管理中安装该文件。
3. 打开画布，添加「合并导出视频」节点。右下角可拖拽调节大小，拉高后清单自动撑满。

## 规则

- 勾选少于 2 个时提示，不执行；未生成的视频不参与合并
- 合并过程可随时停止；出错时显示原始错误信息

## MCP / Agent 函数

| 函数 | 说明 |
| --- | --- |
| `listVideoNodes` | 列出画布上有视频输出的节点：名称、是否已生成、素材路径 |
| `mergeExport` | 执行合并。`nodeIds=[...]` 指定参与合并的节点与顺序；不传则取全部已生成视频节点按名称序合并。返回输出路径与各段时长 |

## 依赖的宿主契约

- `useNode().ffmpeg()`：宿主提供的浏览器 fluent-ffmpeg；concat 清单按清单所在目录解析相对路径（清单内使用 `../../../` 前缀回工作区根）
- 节点输出协议：`data.outputs` 中 `VIDEO` 类型的 `{ url, mimeType }`，`url` 为工作区相对路径
- 画布名取自画布节点 `data.mediaTask.canvasPath`

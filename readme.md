# 合并导出视频 · Toonflow 画布节点插件

作者：山猫

把 Toonflow 画布上视频节点当前显示的素材合并导出为一个 MP4 文件。

## 用法

1. 安装 [shanmaoMergeExport.umd.js](build/shanmaoMergeExport.umd.js)，在画布添加「合并导出视频」节点。
2. 面板按名称自然排序，默认选中已生成的视频。可逐个调整，或用全选快速切换。
3. 点「合并导出」。各段轨道参数一致时，直接流拷贝。存在异档时，先查看分组和差异，再选择基准档。
4. 完成后可以在节点里预览成片，也可以连给下游节点。通过右下角拖拽可调节面板尺寸。

### 流拷贝与转码

- 同档素材直接流拷贝，音画不重新编码。输出为一个新的 MP4。
- 对常见的 H.264（8 位 SDR、逐行、方形像素）与 AAC 基准档，可按选定档对齐异档片段。对齐时保留画面比例，必要时补黑边。
- 只支持一条视频轨和至多一条音轨。音轨有无不一致时会提示。有额外轨道、异档片段带旋转标记或 HDR、基准不支持自动对齐或对齐后仍不兼容时会提示原因。
- 预检读取编码、尺寸、帧率、像素格式、时基、声道等参数。导出后检查成片的轨道、尺寸和时长，验证通过才会发布。

### 输出目录

```text
合并导出视频/
├── 第一集_20261107_041532_74f2e188.mp4
└── input/
    └── 第一集/
        └── 第一集_20261107_041532_74f2e188.txt
```

文件名包含画布名、时间和短编号，同一秒的导出也有独立文件名。清单记录源素材及合并顺序。转码与拼接使用临时文件，导出结束后清理。停止或失败时，节点保留上一次成功的输出。

## Agent 节点操作

| 函数 | 用途 |
| --- | --- |
| `listVideoNodes` | 列出带视频输出的节点、素材路径及已探测到的时长。 |
| `mergeExport` | 传入 `nodeIds` 时按数组顺序导出。省略时使用面板勾选顺序。设置 `allowTranscode: true` 后，允许以段数最多的分组为基准对齐异档。 |

## 构建与测试

使用 Toonflow 插件开发工具准备的 SDK，在项目根目录运行：

```sh
bun run build
bun test
```

其他 SDK 安装位置可设置 `TOONFLOW_PLUGIN_SDK`。构建生成单文件 `build/shanmaoMergeExport.umd.js`，插件标识为 `shanmaoMergeExport`。
